# Smart Complaint & Grievance Management System

## Project Overview

The **Smart Complaint & Grievance Management System (SGMS)** is a frontend-based web application designed to provide a simple, organized, and user-friendly interface for submitting and viewing complaints or grievances.

The system provides separate sections for user login, dashboard access, complaint registration, complaint details, and complaint submission confirmation.

This project is developed using **HTML and CSS only**.

---

## Objectives

- Provide a simple and user-friendly grievance management interface.
- Allow users to register complaints through a structured form.
- Provide different complaint categories and relevant information fields.
- Provide a dashboard for easy navigation.
- Display complaint details and submission status.
- Create responsive web pages for different screen sizes.
- Demonstrate the use of HTML for webpage structure and CSS for styling and layout.

---

## Technologies Used

- **HTML5** – Used to create the structure and content of web pages.
- **CSS3** – Used for styling, layouts, navigation, forms, cards, buttons, and responsive design.

> No JavaScript, backend, or database is used in this version of the project.
